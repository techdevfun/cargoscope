$ cargo cargoscope recommend --from before.json

recommendations (cheapest first — the tool changes nothing; you apply these):

1. [free] Use `cargo check` for the edit/compile loop
   Type checking catches most errors without running codegen or the linker at all.
   gain: Skips the entire codegen+link phase. On this crate that phase is part of the binary units; the win is biggest when your loop is edit -> check -> test, and zero when you already do this.
   snippet:
     # put this in .cargo/config.toml (or ~/.cargo/config.toml)
     [alias]
     checkfast = "check --all-targets"

2. [free] Fix 1 build script(s) that re-run on every build
   A build script with no rerun-if-changed directives re-runs on every single build, invalidating everything downstream. Emit precise directives.
   gain: Removes the script's run time AND the recompile cascade it forces on every no-change build. Measured on your crate by running measure twice.
   snippet:
     # in your build.rs — tell cargo exactly what to watch
     fn main() {
         println!("cargo:rerun-if-changed=build.rs");
         println!("cargo:rerun-if-changed=src/");
         // list ONLY the files/inputs the script reads; never rerun-if-changed=*
     }

3. [install] Switch the linker to mold (Linux)
   mold/lld replace the default GNU ld link step. Only the link step changes; compiled code is identical.
   gain: The final link is typically the single slowest step for large binaries. Only helps if link dominates — check the codegen+link share in the measure output first.
   snippet:
     # .cargo/config.toml — Linux only, needs mold + clang installed
     [target.x86_64-unknown-linux-gnu]
     linker = "clang"
     rustflags = ["-C", "link-arg=-fuse-ld=mold"]

4. [install] Share compilation with sccache
   A compiler cache: identical crates are reused across workspaces, branches and CI machines.
   gain: Near-zero on a single warm machine; large on CI and when switching branches. Does not change what gets compiled, only skips repeats.
   snippet:
     # shell — install sccache, then share the cache across builds/CI
     #   cargo install sccache   (or: apt install sccache / brew install sccache)
     export RUSTC_WRAPPER=sccache
     export SCCACHE_DIR="$HOME/.cache/sccache"

After applying: run `cargoscope measure --json after.json`, then `cargoscope compare before.json after.json`.
